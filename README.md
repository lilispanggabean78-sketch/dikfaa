# 💬 DikFaa — Dimensi Percakapan

Chat aplikasi real-time berbasis web dengan database Upstash Redis.

## ✨ Fitur
- Login dengan email + username
- Group chat & private chat
- Mention user dengan @
- Profile dengan bio + sosmed (Telegram, TikTok, Instagram)
- Toggle aktif/nonaktif sosmed per item
- Dark elegant theme dengan gradien biru-pink

## 🚀 Teknologi
- HTML + CSS + JavaScript (Vanilla)
- Upstash Redis REST API
- Vercel Hosting

## 📁 Struktur File
├── index.html # Halaman loading
├── login.html # Halaman login
├── chat.html # Halaman chat
└── vercel.json # Konfigurasi Vercel


## 🔧 Cara Deploy ke Vercel
1. Fork/Clone repo ini
2. Upload ke GitHub
3. Import ke Vercel
4. Deploy!
